# EcoDrive - Smart Electric Vehicle Rental Management System

EcoDrive is a desktop-based electric vehicle rental management system developed using **C# WinForms**, **Object-Oriented Programming (OOP)**, and **PostgreSQL**.  
The system is designed to simplify electric vehicle rental operations while providing vehicle monitoring and charging station management features.

---

## 📌 About The Project

EcoDrive helps manage electric vehicle rentals such as electric cars and motorcycles efficiently through a centralized system.  
The application supports customer management, vehicle rental transactions, payment processing, vehicle monitoring, and charging status management.

This project was developed as an implementation of:
- Object-Oriented Programming (OOP)
- Database Integration using PostgreSQL
- Desktop Application Development with C# WinForms

---

## 🚀 Main Features

### 👨‍💼 Admin Features
- Login & Logout
- Manage customer data
- Activate / deactivate customer accounts
- Delete customer data
- Add and remove vehicles
- View rental transactions
- Delete unpaid transactions
- Monitor vehicle locations
- Monitor vehicle status
- View total revenue

### 👤 Customer Features
- Register account
- Login & Logout
- View available vehicles
- Filter vehicles by battery and availability
- View vehicle details
- Rent vehicles
- Automatic rental cost calculation
- Payment using balance system
- View transaction history
- Check remaining balance
